NVIDIA Video Codec SDK sample code in the Windows host SteamVR driver

The Windows host SteamVR driver (dist/host/bin/win64/driver_alvr_server.dll), built from ALVR,
contains, in object code only, NVIDIA's NvEncoder, NvEncoderD3D11 and NvCodecUtils sample code
that ALVR incorporates for NVIDIA GPUs (copyright 2017-2022 NVIDIA Corporation).
